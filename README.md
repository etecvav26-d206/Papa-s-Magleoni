# 🍕 Papa's Magleoni Pizzaria — Planejamento do Site

> **Sabor que reúne, momentos que ficam.**

---

## 📋 Sobre o Projeto

Este repositório contém o **planejamento completo** do site institucional da **Papa's Magleoni Pizzaria**, uma pizzaria artesanal fictícia com identidade visual inspirada nas cores da bandeira da Itália (verde, branco e vermelho).

O site foi pensado para apresentar a história da pizzaria, oferecer um cardápio digital aos clientes e, futuramente, contar com um painel administrativo para gestão dos produtos.

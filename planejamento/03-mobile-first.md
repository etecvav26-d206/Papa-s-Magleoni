# Mobile First

O site foi pensado primeiro para telas pequenas. O arquivo `css/styles.css` contém os estilos básicos para celular e usa media queries para adaptar o conteúdo a telas maiores.

## Cuidados adotados

- menu por botão no celular;
- imagens e vídeo ajustados ao espaço disponível;
- cartões em uma coluna nas telas pequenas;
- formulários empilhados no celular;
- textos com tamanho legível;
- uso da meta tag `viewport`;
- cardápio com mais colunas conforme a largura aumenta.

O menu móvel também fecha quando o usuário escolhe um link ou pressiona a tecla Escape.

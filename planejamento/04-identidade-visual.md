## 🎨 Paleta de Cores

A identidade visual é inspirada nas **cores da bandeira italiana** — verde, branco e vermelho — reforçando a temática cultural e a autenticidade da pizzaria.

| Cor | Nome | Hex | Uso |
|-----|------|-----|-----|
| 🟢 | Verde Escuro | `#1E3D2B` | Fundo principal, navbar, seções escuras |
| 🟢 | Verde Claro | `#2A5A3A` | Gradientes, variações de fundo |
| 🟢 | Verde Oliva | `#6B8E23` | Subtítulos, acentos, elementos decorativos |
| 🔴 | Vermelho | `#B22B2B` | Botões, preços, destaques, CTA |
| 🔴 | Vermelho Escuro | `#8A1F1F` | Hover de botões, sombras do vermelho |
| 🟤 | Marrom | `#8C4A2F` | Textos secundários, descrições |
| 🟡 | Creme | `#F2E8D1` | Texto sobre fundo escuro, seção do cardápio |

### Variáveis CSS

```css
:root {
  --green-dark: #1E3D2B;
  --green-olive: #6B8E23;
  --red: #B22B2B;
  --cream: #F2E8D1;
  --brown: #8C4A2F;
  --green-light: #2a5a3a;
  --red-dark: #8a1f1f;
}
```

### Justificativa das Cores

- **Verde** → Tradição, natureza, frescor dos ingredientes, bandeira italiana
- **Vermelho** → Paixão, apetite, energia, tomate, bandeira italiana
- **Creme** → Elegância, aconchego, massa de pizza, sofisticação
- **Marrom** → Terra, madeira do forno a lenha, rusticidade

## 🔤 Tipografia

| Fonte | Tipo | Uso | Origem |
|-------|------|-----|--------|
| **Bebas Neue** | Sans-serif, Display | Títulos, preços, botões, logo | Google Fonts |
| **Montserrat** | Sans-serif | Textos, parágrafos, labels, formulários | Google Fonts |

### Por que essas fontes?

- **Bebas Neue** — Fonte condensada e impactante, com letras maiúsculas que remetem a letreiros de pizzarias tradicionais italianas. Ideal para títulos e destaque visual.
- **Montserrat** — Fonte moderna e legível em todos os tamanhos, garantindo boa leitura tanto em desktop quanto mobile. Os pesos 400, 500, 600 e 700 permitem criar hierarquia visual no texto.

```css
h1, h2, h3, h4, h5, h6 {
  font-family: 'Bebas Neue', sans-serif;
  letter-spacing: 2px;
}

body {
  font-family: 'Montserrat', sans-serif;
}
```

## 🎭 Tom de Comunicação

O tom de voz da marca é **acolhedor, tradicional e confiante**:

- **Acolhedor** — "Sabor que reúne, momentos que ficam"
- **Confiante** — "A melhor pizza artesanal de São Paulo"
- **Tradicional** — "15+ anos de tradição", "Forno a lenha artesanal"
- **Humano** — "Feito com amor", "Do Papa's para a sua família"

O site evita linguagem corporativa fria e busca criar uma **sensação de proximidade**, como se o cliente estivesse sendo recebido em casa.
